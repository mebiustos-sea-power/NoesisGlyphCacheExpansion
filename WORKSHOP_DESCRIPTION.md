# NoesisGUI Glyph Cache Expansion

Sets Sea Power's NoesisGUI glyph cache to **4096 × 4096**.

Increasing the cache may reduce missing characters in affected environments. It applies to every language; it does not translate text or replace fonts. Chinese and Korean may benefit, but have not been tested. This mod does not guarantee that all missing-character problems will be resolved.

## Requirements

- Anchor Chain — Workshop item **3380210757**
- Manual installation of **ACPreloader**, which includes BepInEx

Follow the [AnchorChain installation guide](https://seapower-modders.github.io/AnchorChain/install-anchor-chain.html), subscribe to Anchor Chain and this mod, enable this mod in the game's Mod Manager, then fully exit and restart Sea Power.

Restart the game after enabling or disabling this mod. The plugin checks its own checkbox at startup. Disabling it and restarting restores the game's original cache setting.

The mod contains only the cache-size override. It does not collect diagnostic screenshots or detailed glyph logs.

# NoesisGUI Glyph Cache Expansion

Sea Powerで使われるNoesisGUIの字形キャッシュを **4096×4096** に設定します。

キャッシュの拡大により、環境によっては文字欠けが改善する可能性があります。すべての言語に適用され、翻訳やフォントの差し替えは行いません。中国語・韓国語にも効果が期待できますが、未検証です。すべての文字欠けを解消することを保証するものではありません。

## 必要なもの

- Anchor Chain（Workshop ID **3380210757**）
- ACPreloaderの手動導入（BepInExを含みます）

[AnchorChainの導入手順](https://seapower-modders.github.io/AnchorChain/install-anchor-chain.html)に従ってACPreloaderを導入し、Anchor ChainとこのMODを購読してください。ゲーム内のMOD管理でこのMODを有効にし、ゲームを完全に終了して再起動します。

有効・無効の変更後は再起動が必要です。起動時に自身のチェック状態を確認します。無効にして再起動すると、ゲーム本来のキャッシュ設定に戻ります。

このMODにはキャッシュサイズの変更処理だけが含まれます。診断用のスクリーンショットや字形の詳細ログは採取しません。
